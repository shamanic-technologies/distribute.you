## Wire-shape rules (zod readers)

1. **Probe the payload the consumer ALREADY fetches before asking a producer for anything** ("producer does not serve X" is a claim about a payload; `?groupBy=campaignId` served `outcomes.cpprCents` all along, #3770).
2. **Renamed field left `.nullish()` under its old name reads `undefined` forever** (`totalCostUsd` -> `actualCostUsd`, #402). Grep readers for "renamed from X"; a REQUIRED producer field should be required in the reader. **`new ?? old` only for a pure rename; forbidden when both names are populated and mean different things.**
3. **A parser shared across GRAINS must accept every grain's BODY** (`featureSlug` absent at brand/offer grain; #3468 blanked every brand/offer Overview 2 days). Guard with a REAL PARSE of each grain's body + one rotten body that must still throw (`revenue-parse.ts` imports only zod + a type; keep it).
4. **A MIDDLE service re-declaring an owner's enum rejects values the owner accepts** (email-gateway copy of instantly-service reply kinds -> `Invalid request`). Walk every hop's deployed contract; fix = DELETE the copy and forward, never extend it.
5. **`.optional()` != `.nullable()`**: producer required+nullable => `.nullish()`. A fan-out (per channel/leg) throws whole on one member's null; probe EVERY member (#3614, `pr-expert-quote-opportunities` `outcomes:null`).
6. **A schema written from a SAMPLE is a claim about the sample**: before shipping a reader, parse the producer's WHOLE population through the REAL reader (payload from inside the producer container, `globalThis.fetch` stub in a throwaway vitest). A null meaning "we never looked" must never be GRADED (no red MISSING badge, no `0%`). Cost: Gandi registrar-only `outcaged.com` `dns:null` threw the Domains page (#4291).
7. **A bulk `?domains=`/`?ids=` reader must chunk (<=200), retry transient failures per chunk, filter non-queryable values (`isQueryableDomain`) before chunking, and gate exports on enrichment settled** (admin migrated to server-side `enrich=ahref`; dashboard straggler). Coalesce nullable backend strings before string methods (#2080).
8. **A numeric field declared integer can arrive as a string**: `z.coerce.number().nullable()` + producer issue (#1357). Not-yet-deployed additive field: `.optional()`. Narrow `z.object()` strips new fields; per-VERB schemas; `safeParse` every external reader.
